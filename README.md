One line, 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward.

## Run it

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt`:

> My agent wrote a two-thousand-word post-mortem for the outage it caused today, and blamed human error — mine, in section 3.
